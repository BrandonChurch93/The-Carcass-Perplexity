Made by: the image tool `generate_image` with its default model (through Perplexity), then `assets-src/spine/strikes/make-litcloud.mjs` on Node with the `sharp` of `package-lock.json`.

Prompt or command: the prompt below, then `node assets-src/spine/strikes/make-litcloud.mjs`.

```

A violet-white core of light deep inside heavy cumulonimbus billows in the centre of the picture, the billows nearest it rim-lit and translucent, falling off to pure black along all four edges.
```
